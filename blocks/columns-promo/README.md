# columns-promo

Custom **columns** block. Purpose: Side-by-side promo offers, each with image, heading, text, a Book now button and a secondary link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row; one cell per offer, each holding image, heading, text, primary button link and optional secondary link (the last standalone link is styled as secondary).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
