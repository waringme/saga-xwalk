# newsletter-signup

Custom **custom** block. Purpose: Newsletter subscription panel: icon, heading and intro, first name / last name / email form with Subscribe button, privacy note.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Cells: 1) icon image; 2) heading and intro text; 3) a single link whose href is the form submit URL and whose text is the button label; 4) privacy note with link. The form fields are generated by the block.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
