# cards-cruise

Custom **cards** block. Purpose: Horizontally scrolling row of cruise product cards with previous/next arrows and an "n of N" counter drawn by the block.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card: 1) image; 2) details: heading with the itinerary link, region, departure date, nights; 3) offer badge text (optional, may be empty); 4) price line and small print. The arrows and counter are generated, not authored.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
