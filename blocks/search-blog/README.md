# search-blog

Custom **search** block. Purpose: Blog listing title with a labelled keyword search box; results from the query index are listed under the form.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Cells: 1) heading (optionally followed by a paragraph used as the search label); 2) input placeholder text, e.g. "e.g. destination"; 3) optional query index path or link (defaults to /query-index.json). Results are limited to pages under the current page path when any exist.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
