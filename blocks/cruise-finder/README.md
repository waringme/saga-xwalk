# cruise-finder

Custom **custom** block. Purpose: Cruise search panel with select boxes (cruise type, region, date, passengers) and a Search button that sends the choices to a results page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Optional action row: a single link (text = button label, href = results page). Then one row per select: 1) field label (also the empty first option); 2) bulleted list of options; a bold item is preselected, "Label|value" sets an explicit value.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
