# columns-image-panel

Custom **columns** block. Purpose: Full-width photo with a teal heading tab above the photo edge and a white bordered text panel overlapping the photo on one side.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row with two cells: an image cell (photo + alt) and a text cell (heading, paragraph(s) with inline links, optional standalone 'Find out more' link). The cell order sets the panel side: [image | text] = panel on the right, [text | image] = panel on the left..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
