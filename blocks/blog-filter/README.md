# blog-filter

Custom **columns** block. Purpose: Row of category pill links that filter the cruise blog by topic; the link for the current page is highlighted.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One cell holding a bulleted list (or paragraphs) of category links. The link whose path matches the current page gets aria-current="page".

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
