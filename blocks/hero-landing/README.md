# hero-landing

Custom **hero** block. Purpose: Full-width landing hero: background photo, large title, award badge image and tagline.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Background image first, then title heading, award badge image and tagline, in that order. The first picture is the background; any later picture is a badge.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
